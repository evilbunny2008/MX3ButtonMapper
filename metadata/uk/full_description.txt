MX3 Button Mapper перепризначає апаратні кнопки пультів-аеромишей типу MX3, підключених до пристроїв Google TV, -- кнопки, які «з коробки» надсилають неправильний код клавіші або взагалі нічого корисного.

Застосунок поєднує два механізми Android:

• Службу спеціальних можливостей, яка в усій системі відстежує необроблені скан-коди й може поглинути початкове натискання кнопки.
• Shizuku -- для введення замінного коду клавіші або послідовності натискань замість початкового. Shizuku робить це з тими самими правами оболонки, що вже має 'adb shell input keyevent', тож root не потрібен. Якщо Shizuku не під'єднано, але пристрій має root, застосунок вводитиме клавіші через 'su' і тому попросить доступ суперкористувача у вашого root-менеджера.

Підтримувані типи перепризначення (вбудовано готовий набір за замовчуванням, тож налаштовувати кожну кнопку не потрібно):

• Перепризначити кнопку на інший код клавіші (наприклад, випадкову кнопку Page Up/Page Down -- на справжні «Канал +»/«Канал -»).
• Надсилати той самий код клавіші кілька разів за одне натискання (наприклад, одна кнопка, що надсилає три натискання «Гучність -»).
• Перепризначати кнопку по-різному залежно від застосунку на передньому плані (наприклад, «Канал +/-» у застосунку ТБ, одиночний Page Up/Page Down у Kodi та серія натискань хрестовини для швидкого переходу списками в усіх інших).
• Запускати застосунок просто натисканням кнопки, при цьому утримання тієї ж кнопки й надалі надсилає її звичайне довге натискання (наприклад, натискання «Додому» відкриває MX3 Launcher, а утримання -- довге натискання «Додому»).

Налаштування в застосунку:

• Марка телевізора (TCL або Blaupunkt), адже ці телевізори очікують різні коди для кнопки TV на пульті й використовують різні застосунки для ефірного ТБ.
• Необов'язковий запис натискань клавіш у журнал для діагностики, за замовчуванням вимкнено.
• Мова застосунку -- інтерфейс перекладено приблизно 100 мовами.

Застосунок також налаштовує себе сам через Shizuku: автоматично вмикає власну службу спеціальних можливостей, тож не треба вручну шукати її в «Налаштування -> Спеціальні можливості», може відкривати вибраний вами лаунчер під час запуску, а на телевізорах TCL знову надає дозвіл на автозапуск, який прошивка TCL інакше відкликає, щоб перепризначення працювали й після перезавантаження.

Примітка: деякі перепризначення за замовчуванням для зручності запускають певні сторонні застосунки (наприклад, одразу відкривають лаунчер, відеозастосунок або браузер).
