MX3 Button Mapper 可以重新映射连接到 Google TV 设备的 MX3 类空中飞鼠遥控器的硬件按键 -- 也就是那些出厂时发送错误按键码、或根本发送不出任何有用内容的按键。

它结合了 Android 的两种机制：

• 一个无障碍服务，在整个系统范围内监听原始扫描码，并能拦截（吞掉）原来的按键操作。
• Shizuku，用于注入替代的按键码或按键序列来取代原来的按键。Shizuku 使用的是 'adb shell input keyevent' 本来就有的 shell 级权限，因此无需 root。如果 Shizuku 未连接但设备已 root，应用会改用 'su' 注入按键，因此会向你的 root 管理器请求超级用户权限。

支持的映射类型（内置一套现成的默认映射，因此无需逐个按键配置）:

• 将按键重新映射为另一个按键码（例如把一个错位的 Page Up/Page Down 键改成真正的频道 +/频道 -)。
• 按一次发送多次相同的按键码（例如一个按键发送三次音量减）。
• 根据前台应用以不同方式映射按键（例如在电视应用中为频道 +/-，在 Kodi 中为单次 Page Up/Page Down，在其他地方则为一串方向键按下，用于在列表中快速跳转）。
• 按一下按键直接打开应用，而长按同一按键仍会发送它原本的长按（例如按主页键打开 MX3 Launcher，长按则为主页键长按）。

应用内设置：

• 电视品牌（TCL 或 Blaupunkt），因为这些电视对遥控器 TV 键期望的按键码不同，直播电视应用也不同。
• 可选的按键记录，用于排查问题，默认关闭。
• 应用语言 -- 界面已翻译成约 100 种语言。

应用还会通过 Shizuku 自行完成设置：它会自动启用自己的无障碍服务，无需手动在 设置 -> 无障碍 中查找；启动时可以打开你选择的启动器；在 TCL 电视上，它会重新授予 TCL 固件原本会撤销的自启动权限，让映射在重启后继续有效。

注意：部分默认映射为方便起见会启动特定的第三方应用（例如直接打开启动器、视频应用或浏览器）。
