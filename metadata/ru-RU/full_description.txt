MX3 Button Mapper переназначает аппаратные кнопки пультов-аэромышей типа MX3, подключённых к устройствам Google TV, -- кнопки, которые «из коробки» отправляют неверный код клавиши или вообще ничего полезного.

Приложение сочетает два механизма Android:

• Службу специальных возможностей, которая по всей системе отслеживает необработанные скан-коды и может поглотить исходное нажатие кнопки.
• Shizuku -- для подстановки заменяющего кода клавиши или последовательности нажатий вместо исходного. Shizuku делает это с теми же правами оболочки, что уже есть у 'adb shell input keyevent', поэтому root не нужен. Если Shizuku не подключён, но на устройстве есть root, приложение будет вводить клавиши через 'su' и поэтому запросит доступ суперпользователя у вашего root-менеджера.

Поддерживаемые типы переназначения (встроен готовый набор по умолчанию, поэтому настраивать каждую кнопку не нужно):

• Переназначить кнопку на другой код клавиши (например, случайную кнопку Page Up/Page Down -- на настоящие «Канал +»/«Канал -»).
• Отправлять один и тот же код клавиши несколько раз за одно нажатие (например, одна кнопка, отправляющая три нажатия «Громкость -»).
• Переназначать кнопку по-разному в зависимости от приложения на переднем плане (например, «Канал +/-» в приложении ТВ, одиночный Page Up/Page Down в Kodi и серия нажатий крестовины для быстрого перемещения по спискам во всех остальных).
• Запускать приложение прямо нажатием кнопки, при этом удержание той же кнопки по-прежнему отправляет её обычное долгое нажатие (например, нажатие «Домой» открывает MX3 Launcher, а удержание -- долгое нажатие «Домой»).

Настройки в приложении:

• Марка телевизора (TCL или Blaupunkt), так как эти телевизоры ожидают разные коды для кнопки TV на пульте и используют разные приложения для эфирного ТВ.
• Необязательная запись нажатий клавиш в журнал для диагностики, по умолчанию выключена.
• Язык приложения -- интерфейс переведён примерно на 100 языков.

Приложение также настраивает себя само через Shizuku: автоматически включает собственную службу специальных возможностей, так что не нужно вручную искать её в «Настройки -> Специальные возможности», может открывать выбранный вами лаунчер при запуске, а на телевизорах TCL заново выдаёт разрешение на автозапуск, которое прошивка TCL иначе отзывает, чтобы переназначения продолжали работать после перезагрузки.

Примечание: некоторые переназначения по умолчанию для удобства запускают определённые сторонние приложения (например, сразу открывают лаунчер, видеоприложение или браузер).
