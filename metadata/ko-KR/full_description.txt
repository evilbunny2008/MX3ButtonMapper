MX3 Button Mapper는 Google TV 기기에 연결된 MX3 유형 에어 마우스 리모컨의 하드웨어 버튼을 재지정합니다 -- 기본 상태에서 잘못된 키 코드를 보내거나 쓸모 있는 것을 전혀 보내지 않는 버튼들입니다.

이 앱은 Android의 두 가지 메커니즘을 결합해 작동합니다.

• 시스템 전체에서 원시 스캔 코드를 감지하고 원래 버튼 입력을 소비(삼킴)할 수 있는 접근성 서비스.
• 원래 입력 대신 대체 키 코드나 일련의 입력을 주입하는 데 쓰이는 Shizuku. Shizuku는 'adb shell input keyevent'가 이미 가진 것과 같은 셸 수준 권한으로 이를 수행하므로 루팅이 필요 없습니다. Shizuku가 연결되어 있지 않지만 기기가 루팅되어 있다면 앱이 대신 'su'를 통해 키를 주입하므로 루트 관리자에게 슈퍼유저 권한을 요청합니다.

지원하는 재지정 유형(바로 쓸 수 있는 기본 재지정 세트가 내장되어 있어 버튼별로 설정할 것이 없습니다):

• 버튼을 다른 키 코드로 재지정(예: 엉뚱하게 들어간 Page Up/Page Down 버튼을 제대로 된 채널 +/채널 -로).
• 한 번 누를 때 같은 키 코드를 여러 번 전송(예: 볼륨 낮추기를 세 번 보내는 버튼 하나).
• 포그라운드에 있는 앱에 따라 버튼을 다르게 재지정(예: TV 앱에서는 채널 +/-, Kodi에서는 Page Up/Page Down 한 번, 그 외 모든 곳에서는 목록을 빠르게 이동하도록 방향키 연속 입력).
• 버튼으로 앱을 바로 실행하면서, 같은 버튼을 길게 누르면 여전히 원래의 길게 누르기가 전송됨(예: 홈을 누르면 MX3 Launcher가 열리고, 길게 누르면 홈 길게 누르기가 됨).

앱 내 설정:

• TV 브랜드(TCL 또는 Blaupunkt). 이 TV들은 리모컨의 TV 버튼에 서로 다른 키 코드를 기대하고, 실시간 TV용 앱도 서로 다르기 때문입니다.
• 문제 해결용 키 입력 기록(선택 사항), 기본값은 꺼짐.
• 앱 언어 -- 인터페이스가 약 100개 언어로 번역되어 있습니다.

앱은 Shizuku를 통해 스스로 설정도 합니다. 자체 접근성 서비스를 자동으로 켜므로 설정 -> 접근성에서 직접 찾을 필요가 없고, 시작할 때 선택한 런처를 열 수 있으며, TCL TV에서는 TCL 펌웨어가 평소 회수하는 자동 시작 권한을 다시 부여해 재부팅 후에도 재지정이 계속 작동합니다.

참고: 일부 기본 재지정은 편의를 위해 특정 서드파티 앱을 실행합니다(예: 런처, 동영상 앱 또는 브라우저로 바로 이동).
